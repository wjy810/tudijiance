# 区试田间记载 · 种植图

依据《河南省小麦品种试验记载本（2024-2025）》字段设计的田间种植图与记载工具。纯前端（React + TypeScript + Vite），数据自动保存在浏览器本地，可导出 Excel 记载本。

## 功能

**种植图（试验田 → 区块 → 小区 → 子块，每层操作相同）**

- 每层都可设置行数、列数，以及每一行的高度、每一列的宽度（米）；也可在标尺上直接拖动分隔线调整。
- 合并：选中多个单元后合并，也可按选区合并整行或整列；可拆分。小区内部可再细分成行/列，并同样合并。
- 自定义大小：把区块（或小区、子块）调小后，左右（及上下）默认变为**路面**；该块可在原来填满时的范围内自由拖动，也可用把手或数值调整、对齐、恢复填满。
- 改大内部行列时，上级会自动加宽，同行的其他块保持原尺寸，多出部分为路面。
- 单元类型：种植区 / 路面 / 保护区 / 空地。
- 指北针：显示东南西北，可设置真北方向（北在上/右/下/左，或“以当前屏幕上方为北”）。图四周也标出东南西北。
- 视角：平移模式与旋转模式（拖动自由旋转，按住 Shift 时以 15° 吸附；双指可缩放、旋转），一键正北朝上、旋转 90°、适应窗口；“锁定视角”后无法平移、缩放或旋转。
- 着色：按品种、重复或任一数值字段（热力色）。

**记载本**

- 基本情况：封面、试验设计、栽培管理，以及产量计算参数。
- 品种：代号、名称、对照类别，支持批量粘贴，还可填写品种评价。
- 田间记载：每个小区一行，按重复、按字段分组填写（生育期、茎蘖、抗逆性、倒伏、病害、收获、室内考种）。
- 汇总与产量：小区产量 → 折亩产（÷收获面积×666.67）、±%（比试验平均或比共同对照）、位次；按品种生成性状汇总（含全生育期、成穗率）。
- 气象资料：9月–6月，当年与常年对比。
- 字段设置：区块、小区、子块、基本情况的字段都可增删、改名、排序，可设置类型、单位、选项，以及是否在图上显示。

**文件**

- 导出 Excel：基本情况、田间种植图、种植图布局（含合并）、田间记载、性状汇总表、考种结果、产量表、气象资料、品种评价。
- 导入记载本 `.xls/.xlsx`：读取田间种植图（重复/小区号/品种名、“北”的位置）、基本情况和封面。
- 导出/打开项目 `.json` 文件（完整备份）。

## 操作提示

| 操作 | 方式 |
| --- | --- |
| 选择 | 单击；Shift 单击选矩形范围；Ctrl 单击多选；单击上方/左侧标尺选整列/整行 |
| 进入下一层 | 双击，或在属性面板点“进入内部”；Esc 或面包屑返回上级 |
| 移动缩小后的块 | 直接拖动，或用方向键（按住 Shift 时每步 1 m） |
| 视角 | 滚轮缩放，Shift+滚轮旋转；Q/E 旋转 15°；R 切换旋转模式；L 锁定；F 适应窗口 |
| 撤销/重做 | Ctrl+Z / Ctrl+Y |

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # 网格核心逻辑单元测试
npm run build    # 构建到 dist/（相对路径，可直接部署为静态网站）
```

代码结构：`src/model`（字段定义、网格算法、布局、计算）、`src/map`（种植图、指北针、属性面板）、`src/views`（各记载页）、`src/io`（Excel/JSON 导入导出）。
