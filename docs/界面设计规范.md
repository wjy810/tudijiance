# 小麦品种实验田数字化管理系统 界面设计规范（电脑端）

v1.0 · 2026-10-31

这份规范给以后新做、改做电脑端页面的人用：先看第 1 节的原则，再按第 6 节的模板搭页面，用第 4、5 节现成的组件和样式，最后对照第 9 节的检查清单自查。
手机端（Vant）和数据大屏有自己的风格，只共用颜色、字体这些设计令牌（`client/src/tokens.css`）。

相关文件：

| 文件 | 内容 |
|---|---|
| `client/src/tokens.css` | 设计令牌：颜色、字号、间距、圆角、阴影、动效、布局尺寸（电脑端、手机端共用） |
| `client/src/styles.css` | 电脑端全局样式：页面骨架、通用小部件、Element Plus 组件统一外观 |
| `client/src/fonts.css` | 标题字体思源宋体（只打包粗体，按字符分片按需加载） |
| `client/src/desktop/AppLayout.vue` | 应用框架：侧栏、顶栏、快速跳转 |
| `client/src/desktop/components/` | 通用组件：`PageHeader`、`SectionCard`、`StatCard`、`EmptyState`、`GrowthStageTrack`、`MiniPlotMap`、`CommandPalette` |
| `client/src/assets/art/` | 插画和纹理素材（webp，一般不超过 150 KB） |

## 1. 设计原则

**风格：麦田手记。** 像一本记在田边的笔记本：米色纸张做底，深林绿做骨架，麦穗金点缀，标题用宋体。安静、清楚、耐看，不要花哨。

1. **一页只有一个重点。** 每页最重要的那件事（首页是"现在什么时期、今天该记什么"，平面图是"点小区录数据"）放在最显眼的位置；麦穗金按钮（`.btn-wheat`）一页最多一个，就给它。
2. **先看清，再动手。** 页面从上到下按"概况 → 要做的事 → 明细"排；数字和状态放在操作前面。
3. **少分栏，按"带"排。** 内容整行铺开，一行里可以并排几张等高的卡片，但不要做"主栏 + 窄侧栏"那种两边各自往下长、底部参差不齐的布局（平面图、自助分析这类工具页面除外）。
4. **颜色有含义，不随便用。** 绿 = 正常、完成、主要操作；金 = 当前、重点、提醒；陶土红 = 异常、危险、删除；天青 = 一般信息。装饰一律用纸色和墨色的深浅。
5. **线比阴影多。** 用 1px 细线和留白分组；阴影只给卡片和浮起来的东西（弹出层、悬停的可点卡片）。
6. **数字说话。** 指标用宋体大号数字 + 小号单位，所有数字等宽（`.num`），表格里数值右对齐。
7. **大白话。** 用户是老师和学生：不用术语，按钮写动作（"去录入""导出 Excel"），说明写一句人话；统计术语必须配一句解释。
8. **每个状态都要设计。** 加载中、没有数据、出错、没有权限，都给出说明和下一步能做什么（见第 7 节）。

## 3. 字体和字号

- **标题**：`var(--font-serif)`（思源宋体粗体）。页面标题、卡片标题、对话框标题、指标大数字用它。
- **正文**：`var(--font-sans)`（Windows 上是微软雅黑）。
- **数字**：加 `.num`（等宽数字）；表格已默认等宽。

| 变量 | 大小 | 用在哪 |
|---|---|---|
| `--fs-xs` | 12px | 辅助说明、表头、标签、时间 |
| `--fs-sm` | 13px | 页面说明、面包屑、表格里的次要信息 |
| `--fs-base` | 14px | 正文、按钮、输入框（默认） |
| `--fs-md` | 15px | 列表里的名称 |
| 16px | — | 卡片标题（宋体） |
| `--fs-lg` | 17px | 对话框、抽屉标题（宋体） |
| `--fs-xl` | 20px | 小块里的重点数字 |
| `--fs-2xl` | 24px | 页面标题（宋体） |
| 26px | — | 指标大数字（宋体，`StatCard`） |
| `--fs-3xl` | 30px | 特别大的数字（少用） |

行高：标题 `--lh-tight`（1.3），正文 1.5，说明文字 1.7。宋体标题加一点字间距（0.03–0.06em）。

## 4. 间距、圆角、阴影、动效

**间距**按 4 的倍数：`--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 20 · `--sp-6` 24 · `--sp-8` 32 · `--sp-10` 40 · `--sp-12` 48。

- 页面四周：上 24、左右 32、下 40（`.page` 已经设好）。
- 页面里大块之间：20（`--sp-5`）；同一组卡片之间：14–16。
- 卡片内边距：18–20 × 20；卡片标题和内容之间 14。

**圆角**：`--radius-xs` 6（标签、小按钮）· `--radius-sm` 9（按钮、输入框、列表项）· `--radius` 14（卡片）· `--radius-lg` 18（大卡片、对话框）· `--radius-pill`（胶囊）。

**阴影**：

| 变量 | 用在哪 |
|---|---|
| `--shadow-xs` | 输入框、悬停的小按钮 |
| `--shadow` | 卡片（`.panel`、`SectionCard`、`StatCard`） |
| `--shadow-lift` | 可点卡片悬停时 |
| `--shadow-pop` | 弹出层：下拉、对话框、消息提示 |
| `--ring` | 键盘焦点光圈 |

**动效**：`--dur-fast` 120ms（颜色变化）、`--dur` 200ms（悬停、展开）、`--dur-slow` 320ms（侧栏收起、进度条），缓动用 `--ease`。可点卡片悬停时上浮 1px + `--shadow-lift`；页面区块进场可加 `.fade-up`。系统开了"减少动态效果"时时长自动变 0。

## 5. 应用框架和组件

### 5.1 框架（AppLayout.vue）

```
┌────────┬──────────────────────────────────────────────┐
│ 品牌    │ ☰  日常 › 数据查看        [搜索 Ctrl K] [平面图 ▾] │ ← 顶栏 56px
│────────│──────────────────────────────────────────────│
│ 日常    │                                              │
│ ▌首页 ──┼─ 选中的菜单像书签页，和右边纸面连在一起          │
│  数据查看│            页面内容（.app-content 内部滚动）     │
│ 资料    │                                              │
│  …     │                                              │
│ [用户 ▾]│                                              │
└────────┴──────────────────────────────────────────────┘
```

- **侧栏**宽 224px，可收起到 68px（只剩图标，悬停出提示；状态记在本机）。分组标题小字宽字距；选中项变成纸色"书签页"，图标变金色。
- **加菜单**：只往 `GROUPS` 数组里加一项 `{ path, label, icon, roles }`，放到合适的分组里。面包屑、快速跳转（Ctrl + K）会自动带上它。需要显示待处理条数时加 `badge: () => 数字`（0 或空不显示，收起时变成小圆点）。菜单名 2–6 个字，图标用 `@element-plus/icons-vue`。
- **顶栏**：左边收起按钮 + 面包屑（分组 › 页面；平面图是 首页 › 实验田名）；右边是快速跳转和"平面图"实验田切换（老师、学生可见，点一下直接进那块地的平面图）。
- **内容区** `.app-content` 自己滚动，高度确定：整页工具型页面可以 `height: 100%` 铺满；需要按窗口高度算时用 `calc(100vh - var(--topbar-h) - …)`。

### 5.2 通用组件

**PageHeader** —— 页面标题区。

```vue
<PageHeader title="数据查看" desc="按条件找录入的数据，可以导出成 Excel。">
  <template #actions>
    <el-button :icon="Refresh">刷新</el-button>
    <el-button type="primary" :icon="Download">导出 Excel</el-button>
  </template>
</PageHeader>
```

属性：`title`、`desc`（或 `#desc` 插槽放带链接、数字的说明）、`eyebrow`（标题上方小字）、`plain`（不要标题下的金色短线）。插槽：`#actions`（右边按钮，最多 3 个，主要的放最右）。老页面里手写的 `.page-header` 结构和它的样子完全一样，可以逐步换掉。

**SectionCard** —— 带标题的内容卡片。

```vue
<SectionCard title="最新录入" sub="最近 8 条" :icon="Clock" tone="green" flush>
  <template #actions><el-button link type="primary">查看全部</el-button></template>
  <el-table …/>
  <template #footer>共 115 条</template>
</SectionCard>
```

`flush`：内容贴边（表格、列表用）；`icon` + `tone`（green / wheat / clay / sky）：标题前的小图标块，同一页里最多两三张卡片用图标，别每张都加。老写法 `.panel.panel-pad` + `.panel-title` 仍然可用，样子一致。

**StatCard** —— 一个指标。

```vue
<StatCard label="今天已录" :value="7" :total="36" unit="个小区" tone="green" />
<StatCard label="异常小区" :value="2" unit="个" tone="clay" :icon="Warning" to="/fields/1" />
<div class="stat-row"><StatCard bare … /><StatCard bare … /></div>
```

有 `total` 时显示"值 / 总数"和一条细进度条；`to` 让整张卡片可点；`bare` 放在别的卡片里（去掉边框阴影，几个并排时用竖线隔开，见首页）。一行指标 3–5 个，不要更多。

**EmptyState** —— 空状态：插画 + 一句标题 + 一句说明 + 操作按钮（默认插槽）。`art` 选插画：`field`（实验田）、`data`（数据、记录）、`chart`（图表）、`import`（导入）、`done`（都完成了）。

**GrowthStageTrack** —— 生育期进度条：`<GrowthStageTrack :current="indicators.currentStage" :size="50" />`。8 个主要时期（播种→成熟），分蘖、起身、孕穗、灌浆归到前一个时期；对应规则在 `src/shared/growthStage.ts`（有单元测试）。

**MiniPlotMap** —— 实验田缩略图：`rows`、`cols`、`plots`（大屏接口的 `ScreenPlot`），可选 `labels`（格子里写小区编号，列数 ≤ 12 时才写）、`entered`（今天录过的小区编号，右上角加绿点）。放在土壤纹理底上（`soil.jpg`）。

**CommandPalette** —— 快速跳转，由 AppLayout 提供，页面不用管；全局快捷键 Ctrl + K。

### 5.3 全局样式类（styles.css）

| 类 | 作用 |
|---|---|
| `.page` | 普通页面外层（内边距、最大宽度 1520） |
| `.page-header` / `.page-desc` / `.page-actions` / `.page-eyebrow` | 页面标题区（PageHeader 输出的结构） |
| `.panel` / `.panel-pad` / `.panel-title` (`.sub`) | 卡片 |
| `.filter-bar` + `.filter-label` | 筛选条（放在 `.panel` 上） |
| `.chip` (`.green` `.wheat` `.clay` `.sky`) | 小标签：品种、状态 |
| `.dot` (`.green` …) | 文字前的状态小圆点 |
| `.meter` (`.wheat`) + 里面一个 `<i :style="{ width }">` | 细进度条 |
| `.stat-row` | 一行并排的 `StatCard bare`，中间竖线隔开 |
| `.skeleton` | 骨架占位块（加载中） |
| `.fade-up` | 进场轻轻上浮 |
| `.num` / `.muted` / `.faint` / `.hint` / `.serif` | 等宽数字 / 次要文字 / 辅助文字 / 小号说明 / 宋体 |
| `kbd` | 键盘按键 |
| `.btn-wheat`（加在 el-button 上） | 麦穗金强调按钮，一页最多一个 |

### 5.4 Element Plus 用法约定

- **按钮层级**：麦穗金 `.btn-wheat`（全页唯一的最重要操作）> 绿色 `type="primary"`（卡片、对话框里的主要操作）> 默认按钮（次要操作）> `link`/`text`（表格行内操作、"查看全部"）。删除用 `link type="danger"`，并且要二次确认（`ElMessageBox.confirm`，说清楚删了会怎样）。
- **按钮文字**写动作，2–6 个字；图标放左边，"去××"类跳转按钮箭头放右边（`el-icon--right`）。
- **表格**：表头浅底、细线，不要竖线（`border` 只在需要对齐很多数字列时用）；数值列右对齐；行内操作放最右列，最多 3 个链接按钮，多了收进"更多"。
- **对话框**：宽 420（简单表单）/ 560（一般表单）/ 720–900（带表格）；标题宋体；底部"取消"在左、主操作在右。
- **抽屉**：查看详情、边看边改用抽屉，宽 420–520，从右边出。
- **提示消息**：成功 `ElMessage.success('已保存')`，出错用后端返回的中文提示；不要连着弹多条。
- **下拉选项**超过 7 个加 `filterable`；选项是"年份 + 试验名"这种长文字时设 `min-width`。

## 6. 页面结构模板

### 6.1 列表页（品种、录入项目、用户管理、数据查看）

```vue
<template>
  <div class="page">
    <PageHeader title="品种" desc="试验用的品种，共 12 个。标为对照的品种在统计时作为比较基准。">
      <template #actions>
        <el-input v-model="keyword" placeholder="搜索名称、编号" :prefix-icon="Search" clearable style="width: 240px" />
        <el-button type="primary" :icon="Plus" @click="create">新增品种</el-button>
      </template>
    </PageHeader>

    <div class="filter-bar panel">…筛选条件（可选）…</div>

    <SectionCard flush>
      <el-table :data="rows" v-loading="loading">…</el-table>
      <EmptyState v-if="!loading && rows.length === 0" art="data" title="还没有品种" desc="点右上角"新增品种"。" />
      <template #footer><el-pagination … /></template>
    </SectionCard>
  </div>
</template>
```

要点：搜索框和新增按钮放标题右边；筛选条件多于 3 个才单独做筛选条；表格贴边；空表格用 EmptyState 替换，不用表格自带的"暂无数据"。

### 6.2 详情页（实验田、某个品种、某条记录）

```
PageHeader（标题 = 对象名称；eyebrow = 类型；右边：编辑、更多）
一行 StatCard（3–5 个关键数字）
SectionCard：主体内容（图、表）
SectionCard：相关记录 / 修改记录
```

返回上一级靠顶栏面包屑，页面里不再单独放"返回"按钮。

### 6.3 分析页（统计分析、自助分析、数据检查）

```
PageHeader（说明里写清楚"这一页算的是什么"，统计术语配一句解释）
筛选条 .filter-bar.panel：实验田 → 试验 → 项目（用 useTrialPicker 记住上次选的）
SectionCard：结果表（右上角"导出 Excel"）
SectionCard：图表（EChart；没数据时 EmptyState art="chart"）
```

工具型页面（自助分析、平面图）可以用"左面板 + 主区"的整页布局（`height: 100%`），面板宽 240–280；窄窗口（< 1500px）时把右侧面板移到主区下面。

### 6.4 首页（仪表）

```
PageHeader（问候 + 一句话概况，plain）
当前实验田大卡片：名称、试验、生育期进度条、3–4 个指标、主要操作 | 右边平面图缩略图
今天该记什么（SectionCard，TodayTodoPanel）
需要处理：一行 2–3 张可点卡片（异常小区、数据检查、更正申请）
最新录入（SectionCard flush，紧凑表格）
全部实验田（两块以上时，卡片网格）
```

分组标题的写法：**一张卡片 → 标题写在卡片里**（SectionCard）；**一组并排的卡片 → 标题写在外面**（宋体 16px，旁边可跟一句小字）。

## 7. 空状态、加载、出错

| 状态 | 做法 |
|---|---|
| 第一次加载 | 整块内容用 `.skeleton` 占位（形状接近真实内容），不要整页转圈；局部刷新（换筛选条件）用 `v-loading` 盖在那张卡片上 |
| 没有数据 | `EmptyState`：说清楚为什么空，下一步怎么做；有权限的给一个按钮（例如老师看到"新建实验田"，学生看到"请老师先建实验田"） |
| 查询结果为空 | 一句话即可："这个范围里没有数据，换个年份或品种试试" |
| 全部完成 | `EmptyState art="done"`，说一句鼓励的话 |
| 出错 | 卡片里显示 EmptyState：标题"没取到××"，说明里带上后端的中文提示 + "检查一下网络或服务器"，按钮"再试一次"；操作失败用 `ElMessage.error` |
| 还没开放 / 没权限 | 卡片变淡、不能点，旁边一个 `.chip`"即将开放"；没权限的入口直接不显示 |

## 8. 文案

- 称呼用户用"你"；按钮用动词开头；说明一句话说完，不超过两行。
- 用"小区、实验田、试验、录入项目、对照品种"这些大家熟悉的词，不用"实体、记录集、字段映射"。
- 数字和单位之间空一格（`36 个小区`、`76 cm`），中文和数字之间空一格。
- 日期在页面上写"10 月 31 日"或"今天 14:30"，表格和导出里写 `2026-10-31`。
