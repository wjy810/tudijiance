# 小麦品种实验田数字化管理系统：硬件设备需求（v0.1）

依据 [需求分析 v0.3](需求分析.md)、[技术选型 v0.1](技术选型.md) 和 NY/T 1301—2025（见 [记载标准摘要](记载标准摘要_NY-T1301-2025.md)）。

本文不列价格，因为价格变化快。询价后填进第 7 节的采购清单。

## 1. 总览

| 阶段 | 类别 | 设备 |
|---|---|---|
| 阶段一 | 计算设备和网络 | 服务器、Windows 电脑、大屏、安卓手机、网络 |
| 阶段一 | 田间记载用品 | 打印机、小区标识牌、二维码标签（建议） |
| 阶段一 | 测量仪器（按标准） | 卷尺、量角器、电子天平、容重器、电子台秤等 |
| 阶段二 | 物联网 | 土壤传感器、小型气象站、4G DTU、太阳能供电、机箱和防雷、摄像头（可选） |
| 阶段三 | 无新增 | 服务器加内存 |

## 2. 阶段一：计算设备和网络

### 2.1 服务器（我们自己提供）

| 项 | 阶段一 | 阶段二、三 |
|---|---|---|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB（阶段三要运行 Python 分析服务） |
| 硬盘 | 50 GB SSD | 100 GB 以上（如果加摄像头） |
| 系统 | 能装 Docker 的 64 位 Linux，如 Ubuntu Server LTS | 同左 |
| 网络 | 最好能从外网访问（公网 IP 或域名）。否则田间只能离线录入，回到校内再同步 | 同左；传感器数据要从田里通过 4G 发到服务器，必须能从外网访问 |
| 其他 | 如果是放在机房的实体机，建议配 UPS；需要另一台机器或网盘存放备份 | 同左 |

**硬盘估算**：照片按标准每个品种每年约 6 张、每张 0.5 MB 计算，100 个品种一年约 300 MB；加上其他照片和数据，一年不超过 2 GB。50 GB 足够用好几年。

### 2.2 电脑（桌面应用）

| 项 | 要求 |
|---|---|
| 系统 | Windows 11（Windows 10 也可以，以 Electron 官方支持为准），64 位 |
| 内存 | 8 GB 及以上 |
| 屏幕 | 1920×1080 及以上。平面图编辑和录入网格都要比较大的屏幕 |
| 数量 | 实验室 1–2 台，先用现有电脑 |

### 2.3 大屏（看仪表板）

- 55 英寸以上的电视或投影仪，带 HDMI 接口。
- 接一台电脑，运行桌面应用的全屏仪表板。
- 可以先用学院现有的会议室或实验室显示设备。

### 2.4 安卓手机（1B 阶段）

| 项 | 要求 |
|---|---|
| 系统 | 软件最低支持 Android 7.0（Capacitor 8 的下限）<br>新买的手机建议 Android 12 及以上：国内手机没有 Google Play，系统 WebView 要靠厂商系统更新，老手机的 WebView 可能太旧 |
| 屏幕 | 6.5 英寸以上，户外强光下看得清 |
| 电池 | 5000 mAh 以上，另配充电宝 |

| 存储 | 128 GB 以上。离线时照片先存在手机里 |

### 2.5 网络

- **实验室**：校园网或 Wi-Fi。
- **田间**：用 4G/5G 手机信号。要到地里实测一下信号强度；没信号时用离线录入。
- 阶段二的 4G DTU 也依赖田间信号。

## 4. 阶段一：测量仪器（按 NY/T 1301—2025）

系统里每个数值保留几位小数是按标准定的，仪器精度要跟得上。这些仪器学校可能已经有，**先盘点，再采购**。

| 测量项目 | 标准条款 | 仪器 | 精度和量程 |
|---|---|---|---|
| 株高 | A.2.2.5 | 钢卷尺或直尺 | 1 cm（结果取整数） |
| 基本苗、最高茎蘖数、有效穗数 | A.2.3 | 米尺，加标记 1 m 样段用的标记杆或彩绳 | — |
| 倒伏角度 | A.2.4.5 | 量角器或坡度仪；手机自带的测角功能也可以 | 能分清 30°、45°、60° 这几个分级界限 |
| 每穗粒数、黑胚率 | A.3.1、A.3.7 | 数粒板或自动数粒仪（可选）、放大镜 | — |
| 千粒重 | A.3.5 | 电子天平 | 精度 0.01 g，量程 100 g 以上<br>结果保留 1 位小数，两次相差超过 0.5 g 要重测 |
| 容重 | A.3.6 | 谷物容重器，按 GB/T 5498 测定 | 两次相差超过 5 g/L 要重测 |
| 小区产量 | A.3.8 | 电子台秤 | 精度 0.01 kg（结果保留 2 位小数）<br>量程按最大的小区产量选；13.3 m² 的小区一般十几公斤 |
| 籽粒含水量（可选） | 判断籽粒是否已经风干 | 粮食水分测定仪 | — |
| 考种照片 | 8.2.2 | 蓝色或红色背景板，可以加小型摄影灯箱 | — |
| 土壤取样 | 需求 4.4 L 组 | 土钻（0–20 cm）、取样袋、标签 | 化验在哪里做待确认 |

- **气象**：阶段一不买气象设备。数据从气象部门或气象数据服务获取后导入（需求 4.4 M 组）。
- **可选**：带 RS232 或 USB 输出的天平和台秤，可以把读数直接传进桌面软件，减少抄写错误。这需要软件支持，后期再考虑。

## 5. 阶段二：物联网设备

### 5.1 系统组成

```
土壤传感器、气象站传感器（RS485 / Modbus RTU）
        │ 屏蔽电缆
4G DTU（定时读取传感器，用 MQTT 发出）
        │ 4G 网络
服务器上的 Mosquitto → 后端 → 数据库

太阳能板 → 充放电控制器 → 蓄电池 → DTU 和传感器
```

传感器统一用 RS485 接口和 Modbus RTU 协议，这样一台 DTU 可以接多个传感器，换品牌也不用改软件的接入方式。

### 5.2 土壤传感器

| 项 | 要求 |
|---|---|
| 测量项 | 土壤温度、含水量、电导率、pH；氮磷钾可选 |
| 接口 | RS485，Modbus RTU |
| 防护 | IP68，能长期埋在土里 |
| 埋设深度 | 0–20 cm 层，和土壤化验的取样深度一致；需要时再加一层 20–40 cm |
| 布点 | 不必每个小区一个。建议每块实验田 3–5 个点，比如每个重复（区组）一个。小区之间的土壤差异靠化验 |
| 氮磷钾精度 | 低价的氮磷钾传感器多数是根据电导率估算的，精度有限，只能看变化趋势，不能代替化验 |
| 田间作业 | 翻耕、播种、机收前要避开或取出传感器；电缆沿走道或保护区敷设，并做好标记 |
| 维护 | pH 传感器会漂移，每年对照化验结果校准一次 |

### 5.3 小型气象站

测量项对应需求 4.4 的 M 组：

| 测量项 | 传感器 | 安装 |
|---|---|---|
| 气温、相对湿度 | 温湿度传感器，加防辐射罩 | 离地 1.5 m |
| 降水量 | 翻斗式雨量计 | 承水口保持水平，周围无遮挡，定期清理 |
| 风速、风向 | 风速风向传感器 | 装在立杆顶部 |
| 日照时数 | 日照计；也可以用总辐射传感器近似换算，但精度较低 | 周围无遮挡 |
| 地温 | 地温传感器（可以和土壤传感器合用） | 5、10、20 cm |

- **位置**：装在实验田边、保护区外开阔的地方。照片里实验田四周有成排的树，要避开树影和建筑的遮挡。
- **数量**：每个试验地点 1 套。
- **采样**：每 5–10 分钟采一次。每天的最高、最低、平均气温，以及累计降水量、日照时数，由服务器计算。

### 5.4 数据采集和通信

| 设备 | 要求 |
|---|---|
| 4G DTU（数据传输单元） | 带 RS485 接口，能定时轮询 Modbus 传感器<br>支持 MQTT，最好支持 TLS 加密<br>断网时能缓存数据，断线后自动重连<br>低功耗，工业级宽温 |
| 物联网卡 | 4G 流量卡。数据量很小：20 个测量值每 10 分钟上报一次，每月预计几十 MB 以内 |
| 布线 | 传感器到 DTU 用屏蔽双绞线，尽量短 |
| 备选方案 | 测点多、分布远时，改用 LoRa 无线节点加 LoRa 网关，网关再用 4G 上传 |

### 5.5 供电

田里一般没有市电，用太阳能供电：太阳能板 + 充放电控制器 + 蓄电池（磷酸铁锂或胶体铅酸）。

**估算方法**：

1. 把 DTU、传感器（和摄像头）的功率加起来，算出每天耗电多少瓦时（Wh）。
2. 蓄电池按连续 5 个阴雨天计算：容量 = 日耗电 × 5 ÷ 可用放电深度。
3. 太阳能板功率 ≈ 日耗电 ÷ 当地日均峰值日照小时 ÷ 系统效率（约 0.7），再留余量。

**示例**：平均负载 5 W 时：

- 每天耗电 120 Wh，5 天就是 600 Wh；
- 磷酸铁锂电池按 80% 可用，需要约 750 Wh，即 12 V 60 Ah 左右；
- 峰值日照按 4 小时算，太阳能板需要约 120 ÷ 4 ÷ 0.7 ≈ 43 W，选 80–100 W 的板。

选定设备后要按实际功率重新计算。加摄像头时功耗会明显增加，要单独算。如果田边有市电，用 12 V 或 24 V 电源适配器加小型 UPS 更简单。

### 5.6 安装和防护

- **机箱**：IP65 以上的防水机箱，装 DTU、充放电控制器和蓄电池。
- **立杆**：立杆加混凝土地笼基础。
- **防雷**：
  - 空旷田地容易遭雷击，要装避雷针并做好接地。
  - 电源线和 RS485 线路要加防雷器（浪涌保护器）。
- **防损坏**：加围栏或护网。标准 6.5 要求防止人、鼠、鸟、畜、禽对试验造成损害。
- **标识**：设备上挂标识牌，写明用途和联系人。

### 5.7 摄像头（可选）

- **用途**：定时拍照，补充标准 8.2 要求的拔节期、灌浆期、成熟期全景照；也可以远程查看。
- **要求**：4G 联网，能定时抓拍并上传。功耗一般在几瓦到十几瓦，要单独计算供电。
- **局限**：定时照片不能完全代替标准要求的照片。标准要求给每个品种拍第 1 重复、带标识牌的全景照。
- 可以放到阶段二后期再做。

## 8. 待确认的问题

1. **现有仪器和设备**：学校现在有哪些？例如电子天平、容重器、台秤、水分仪、打印机、电脑、大屏。先盘点再采购。
2. **田间条件**：实验田有没有市电？田里 4G 信号怎么样？离最近的有 Wi-Fi 的建筑多远？
3. **小区和田间作业**：实验田一共有多少个小区？每年翻耕吗？用机器收获吗？这决定标识牌数量和传感器怎么埋。
4. **手机**：由学校统一配发，还是用个人手机？
5. **摄像头**：阶段二要不要装？
6. **预算**：采购预算大概是多少？
