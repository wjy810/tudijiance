## 1. 哪些手动录入，哪些自动采集

### 1.1 判断方法

**自动采集**：能用传感器直接测量、随时间不断变化、需要频繁记录的数值。阶段一只做三项：**土壤温度、湿度、pH**。

**手动录入**：其余所有数据，分四类：

1. **人做的事**：传感器不知道哪天施了肥。例如播种、拔苗、施肥、浇水、打药。
2. **要靠人看、数、判断的**：例如出苗期、抽穗期、倒伏级别、病害级别、苗数。
3. **要先取样、再用仪器测的**：例如千粒重、容重、产量、土壤肥力化验。
4. **基本不变的信息**：例如实验田、小区、品种。

### 1.2 阶段一的数据分工

| 数据（需求分析 4.4 的分组） | 方式 | 用到的设备 |
|---|---|---|
| A 基础信息（实验田、小区、品种） | 手动 | 电脑 |
| B 农事操作（拔苗、施肥、浇水等） | 手动 | 电脑、手机 |
| C 物候期（出苗、抽穗、成熟等） | 手动 | 目测 |
| D 形态特征（株高、穗形等） | 手动 | 卷尺 |
| E 生育动态（基本苗、有效穗数等） | 手动 | 米尺、样段标记 |
| F 抗逆性（冻害、倒伏等） | 手动 | 目测、量角器 |
| G 病虫害 | 手动 | 目测 |
| H 考种和产量 | 手动：仪器测完后录入 | 电子天平、容重器、电子台秤 |
| I 品质和抗性鉴定 | 手动：导入送检结果 | — |
| K 异常情况 | 手动 | — |
| **L 土壤温度、湿度、pH** | **自动** | **土壤传感器 + 4G DTU** |
| L 土壤肥力（有机质、氮、磷、钾等） | 手动：化验后录入 | 土钻、取样袋 |
| M 气候（气温、降水、日照等） | 手动：从气象数据导入 | — |
| J 照片、视频 | 阶段二 | — |

土壤 pH 有两个来源：传感器连续测得的 pH 用来看变化趋势；化验测得的 pH 更准，每年用它校准一次传感器。

## 2. 自动采集设备

### 2.1 组成

```
土壤三合一传感器（温度、湿度、pH）
        │ RS485 屏蔽电缆（Modbus RTU 协议）
4G DTU：定时读取传感器，用 MQTT 发出
        │ 4G 网络
服务器：Mosquitto → 后端 → 数据库 → 图表

供电：太阳能板 → 充放电控制器 → 蓄电池 → DTU 和传感器
（田边有市电时，改用电源适配器）
```

传感器统一用 RS485 接口和 Modbus RTU 协议。这样一台 DTU 可以接多个传感器，以后加传感器或换品牌，软件的接入方式都不用改。

### 2.2 土壤传感器

| 项 | 要求 |
|---|---|
| 测量项 | 土壤温度、土壤湿度（体积含水量）、土壤 pH。选三合一的，一个探头测三项 |
| 接口 | RS485，Modbus RTU |
| 供电 | 12 V 或 24 V 直流，和 DTU 一致 |
| 防护 | IP68，能长期埋在土里 |
| 埋设深度 | 0–20 cm 土层，和土壤化验的取样深度一致；探头要和土壤贴紧 |
| 数量 | 先装 1 个点，把"传感器 → 服务器 → 图表"全流程打通；稳定后再扩到每块实验田 3–5 个点，比如每个重复一个 |
| 采样间隔 | 每 30 分钟一次。土壤温度、湿度和 pH 变化慢，不需要更频繁 |
| 田间作业 | 翻耕、播种、机收前要避开或取出；电缆沿走道或保护区敷设，并做好标记 |
| 校准 | pH 会漂移，每年对照化验结果校准一次<br>湿度读数和土质有关，最好用烘干法测一次含水量做对照 |

如果"温度、湿度"还包括空气温湿度，就再加一个 RS485 空气温湿度传感器，接在同一台 DTU 上。它要加防辐射罩，装在离地 1.5 m 处。见第 7 节问题 1。

### 2.3 4G DTU 和物联网卡

| 设备 | 要求 |
|---|---|
| 4G DTU（数据传输单元） | 带 RS485 接口，能定时轮询 Modbus 传感器<br>支持 MQTT，最好支持 TLS 加密<br>断网时能缓存数据，断线后自动重连<br>低功耗，工业级宽温<br>最好能控制传感器供电（读数时才通电），更省电 |
| 物联网卡 | 4G 流量卡。数据量很小：5 个点每 30 分钟上报一次，每月预计几十 MB 以内 |

### 2.4 开发调试用

传感器装到地里之前，先在桌面上调通：

- **USB 转 RS485 转换器**：把传感器直接接到电脑上，用 Modbus 调试工具读数，确认寄存器地址和数值换算方法。参考论文也是用 ModBus Poll 调试的。
- **12 V 电源适配器**：桌面调试时给传感器和 DTU 供电。

### 2.5 供电

田里一般没有市电，用太阳能供电：太阳能板 + 充放电控制器 + 蓄电池（磷酸铁锂或胶体铅酸）。

**估算方法**：

1. 把 DTU 和传感器的功率加起来，算出每天耗电多少瓦时（Wh）。
2. 蓄电池按连续 5 个阴雨天计算：容量 = 日耗电 × 5 ÷ 可用放电深度。
3. 太阳能板功率 ≈ 日耗电 ÷ 当地日均峰值日照小时 ÷ 系统效率（约 0.7），再留余量。

**示例**：平均负载 2 W 时：

- 每天耗电 48 Wh，5 天就是 240 Wh；
- 磷酸铁锂电池按 80% 可用，需要约 300 Wh，即 12 V 25 Ah 左右；
- 峰值日照按 4 小时算，太阳能板需要约 48 ÷ 4 ÷ 0.7 ≈ 17 W，选 30–50 W 的板。

选定设备后要按实际功率重新计算。如果田边有市电，用电源适配器加小型 UPS 更简单。

### 2.6 安装和防护

- **机箱**：IP65 以上的防水机箱，装 DTU、充放电控制器和蓄电池。
- **立杆**：立杆加混凝土基础。
- **防雷**：
  - 空旷田地容易遭雷击，要装避雷针并做好接地。
  - 电源线和 RS485 线路要加防雷器（浪涌保护器）。
- **防损坏**：加围栏或护网。标准 6.5 要求防止人、鼠、鸟、畜、禽对试验造成损害。
- **标识**：设备上挂标识牌，写明用途和联系人。

### 3.3 测量仪器（按 NY/T 1301—2025）

系统里每个数值保留几位小数是按标准定的，仪器的精度要跟得上。这些仪器学校可能已经有，**先盘点，再采购**。

| 测量项目 | 标准条款 | 仪器 | 精度和量程 |
|---|---|---|---|
| 株高 | A.2.2.5 | 钢卷尺或直尺 | 1 cm |
| 基本苗、最高茎蘖数、有效穗数 | A.2.3 | 米尺，加标记 1 m 样段用的标记杆或彩绳 | — |
| 倒伏角度 | A.2.4.5 | 量角器或坡度仪；手机自带的测角功能也可以 | 能分清 30°、45°、60° 三个分级界限 |
| 每穗粒数、黑胚率 | A.3.1、A.3.7 | 数粒板或自动数粒仪（可选）、放大镜 | — |
| 千粒重 | A.3.5 | 电子天平 | 精度 0.01 g，量程 100 g 以上 |
| 容重 | A.3.6 | 谷物容重器，按 GB/T 5498 测定 | — |
| 小区产量 | A.3.8 | 电子台秤 | 精度 0.01 kg；量程按最大的小区产量选，13.3 m² 的小区一般十几公斤 |

## 4. 服务器和网络

**服务器（我们自己提供）**

| 项 | 要求 |
|---|---|
| 配置 | 2 核 CPU、4 GB 内存、50 GB SSD |
| 系统 | 能装 Docker 的 64 位 Linux，如 Ubuntu Server LTS |
| 网络 | **必须能从外网访问**（公网 IP 或域名）。DTU 要从田里通过 4G 把数据发到服务器，所以阶段一就需要。<br>如果学校服务器只能在校内访问，可以另租一台小云服务器专门接收传感器数据，或者请学校开放 MQTT 端口 |
| 其他 | 放在机房的实体机建议配 UPS；需要另一台机器或网盘存放备份 |

**网络**

- **实验室**：校园网或 Wi-Fi。
- **田间**：DTU 和手机都要用 4G 信号，安装前要到地里实测信号强度。
- **没有信号时**：DTU 可以改用 LoRa 无线传到有网络的地方，再由网关上传；手机用离线录入。

## 7. 待确认的问题

1. **"温度、湿度"指什么？** 本文按土壤温度和土壤湿度理解，和 pH 用同一个三合一探头。如果也要空气温湿度，就加一个空气温湿度传感器（见 2.2）。
2. **手机拍照算不算阶段二？** 视频图像放到阶段二，本文把手机拍照也一起放到了阶段二。
3. **服务器能不能从外网访问？** 现在是必须的，见第 4 节。
4. **实验田条件**：有没有市电？田里 4G 信号怎么样？
5. **田间作业**：每年翻耕吗？用机器收获吗？这决定传感器能不能长期埋在地里。
6. **现有仪器**：学校现在有哪些？例如电子天平、容重器、台秤、电脑、打印机。
7. **手机**：由学校统一配发，还是用个人手机？
8. **预算**：采购预算大概是多少？
