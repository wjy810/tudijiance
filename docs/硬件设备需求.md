# 小麦品种实验田数字化管理系统 硬件设备需求

v0.3 · 2026-10-30 · 依据 [需求分析 v0.6](需求分析.md)

第一期的数据全部手动录入，不需要传感器；传感器等自动采集设备到第二期再定（见第 2 节）。本文不列价格，询价后填进第 3 节的采购清单。

## 1. 第一期需要的设备

### 1.1 手机（主要录入设备）

老师和学生在田间用手机录入。

| 项 | 要求 |
|---|---|
| 系统 | 安卓 7.0 及以上（软件的最低要求）。新买的建议安卓 12 及以上：国内手机的浏览器内核要靠厂商系统更新，老手机的可能太旧 |
| 屏幕 | 6.5 英寸以上，户外强光下看得清 |
| 电池 | 5000 mAh 以上，另配充电宝 |
| 防护 | 防水防尘（IP67 或 IP68），或加防水壳 |
| 网络 | 4G 或 5G；田里没信号时可以先存在手机上，有网后上传 |
| 存储 | 64 GB 以上 |
| 数量 | 每个录入人员一台 |

### 1.2 电脑

老师设置实验田和品种、导入历史表格、查看统计；系统管理员管理用户。

- Windows 11（Windows 10 也可以），64 位；内存 8 GB 及以上；屏幕 1920×1080 及以上。
- 1–2 台，先用现有的。

### 1.3 大屏

给游客看的大屏展示。

- 55 英寸以上的电视或投影仪，带 HDMI 接口，再接一台电脑运行大屏页面。
- 先用学院现有的显示设备。

### 1.4 服务器和网络

| 项 | 要求 |
|---|---|
| 服务器配置 | 2 核 CPU、4 GB 内存、50 GB 硬盘；装 Docker 的 64 位 Linux |
| 外网访问 | 最好有公网 IP 或域名，手机在田里用流量就能上传；没有的话，回到校内网络再同步 |
| 备份 | 另一台机器或网盘，用来存每天的数据备份 |
| 田间信号 | 到地里实测一下手机信号 |

服务器由我们自己提供。

### 1.5 田间用品

| 用品 | 用途 |
|---|---|
| 小区标识牌和插杆 | 在田里认小区。防水耐晒的 PVC 牌或铝牌，写小区编号和品种 |
| 防水记录本、铅笔 | 手机没电或出故障时临时记录 |
| 二维码标签（建议，待确认） | 贴在标识牌上，手机扫码直接打开该小区的录入页面 |

### 1.6 测量仪器

按 NY/T 1301—2025，系统里每个数值保留几位小数是定好的，仪器精度要跟得上。学校可能已经有这些仪器，**先盘点，再采购**。

| 测量项目 | 仪器 | 精度和量程 |
|---|---|---|
| 株高 | 钢卷尺或直尺 | 1 cm |
| 基本苗、有效穗数 | 米尺，加标记 1 m 样段用的标记杆或彩绳 | — |
| 倒伏角度 | 量角器或坡度仪；手机的测角功能也可以 | 能分清 30°、45°、60° |
| 千粒重 | 电子天平 | 精度 0.01 g，量程 100 g 以上 |
| 容重 | 谷物容重器 | 按 GB/T 5498 |
| 小区产量 | 电子台秤 | 精度 0.01 kg，量程按最大的小区产量选 |
| 每穗粒数、黑胚率 | 数粒板、放大镜；自动数粒仪可选 | — |
| 土壤取样 | 土钻（0–20 cm）、取样袋 | 化验在哪里做待确认 |

## 2. 第二期：自动采集设备（待定）

老师的意见是：自动采集放到后期，采集哪些数据、用什么格式现在还定不了，第一期软件只预留接口。

之前讨论过的方向，供第二期参考：

- 土壤温度、湿度、pH 三项被认为是最基础的，可以用一个土壤三合一传感器测；
- 小型气象站（气温、降水、风、日照）；
- 田间摄像头和各生育期的照片（图像视频）。

传感器、DTU、太阳能供电、防雷等的详细方案写在[硬件设备需求 v0.2](https://github.com/wjy810/tudijiance/blob/5779ec07649cd710b95e274b0a4a95f85f22bec5/docs/%E7%A1%AC%E4%BB%B6%E8%AE%BE%E5%A4%87%E9%9C%80%E6%B1%82.md) 里，第二期确定数据和格式后再用。
