# 小麦品种实验田数字化管理系统：需求分析（v0.2）

| 版本 | 内容 |
|---|---|
| v0.1 | 根据老师的语音消息整理初稿 |
| v0.2 | 根据确认结果修改：重新划分开发阶段，补全录入项目，加入小区可视化编辑、预设与自定义、动态图表 |

原始需求见 [聊天记录截图](老师需求聊天记录.webp)，老师原话和本文各章节的对应关系见[附录](#附录老师原话对照)。

## 1. 背景与目标

- **对象**：学校的小麦品种实验田。整块地按横向、纵向划分成若干个小区，每个小区种一个品种。
- **目标**：做一个实验田数字化管理系统，**在手机 APP 上录入，数据统一存到服务器**。试验连续多年进行，数据要长期积累，用来做图表展示、品种对比，最后做品种推荐。

## 2. 已确认的事项

| 事项 | 结论 |
|---|---|
| 客户端 | 手机原生 APP，安装在手机上使用（不做小程序或网页） |
| 服务器 | 我们自己提供 |
| 历史数据 | 没有往年数据要导入，从零开始积累 |
| 实验田和小区 | 做成可视化编辑：老师自己设定有几块田、每块几行几列，编号规则可以多选、批量设置（见 4.1） |
| 生育期和农事操作 | 系统给出多个预设项目，老师还可以自定义（见 4.2） |
| 记录内容 | 不只记日期，相关的数值都要记；录入项目要全面（见 4.3） |
| 图表形式 | 仿照九数云仪表板的动态形式（见 4.4） |
| 开发阶段 | 阶段一手动录入全部数据，阶段二用物联网传感器自动采集，阶段三做统计分析和决策（见第 3 节） |

## 3. 开发阶段总览

| 阶段 | 内容 | 数据从哪来 |
|---|---|---|
| **阶段一** | 实验田和小区管理，**全面的手动录入**（包括土壤和气候参数），可视化图表，品种对比 | 人在手机上录入 |
| **阶段二** | 物联网传感器自动采集（土壤、气象等），自动采集的数据和手动录入的数据合在一起展示 | 传感器自动上传 + 手动录入 |
| **阶段三** | 统计分析与决策：总结品种特性档案，根据地块条件推荐试种品种 | 阶段一、二多年积累的数据 |

和 v0.1 相比的变化：

- 老师提到的品种特性（抗逆、抗倒伏）原来放在"后期补充"。现在这些观测指标在**阶段一就手动录入**，到阶段三再把多年的数据汇总成品种特性档案。
- 老师在第三段话里提到的地块形状、土壤肥力、酸碱度、气候条件，现在也在**阶段一就手动录入**，阶段二再改由传感器自动采集。

## 4. 阶段一：全面手动录入 + 可视化

### 4.1 实验田和小区的可视化编辑

- **新建实验田**：老师自己新建实验田，可以有多块。每块田设定行数和列数，系统自动生成小区网格。
- **多选小区**：在网格上点选、框选，或者整行、整列选中。
- **批量编号**：对选中的小区批量应用编号规则。预设几种常用规则，也可以设置前缀和起始号：
  - 按行顺序编号：1、2、3……
  - 蛇形编号：第一行从左到右，第二行从右到左（田间试验常用）
  - 行号-列号：如 `3-05`
  - 前缀 + 流水号：如 `A001`、`A002`
- **批量分配品种**：选中多个小区，一次指定品种。
- **特殊格子**：可以把某些格子标记成保护行、走道或空地，不参与统计。
- **按年度管理布局**：每年各小区种的品种可能不同。新一年可以复制上一年的布局，再在上面修改。
- **平面图着色**：平面图上可以按品种、生育期进度或任意一个指标的数值上色（热力图），点击小区查看详情。

### 4.2 预设项目 + 自定义

- 系统**预设**生育期、农事操作、观测指标、灾害类型这几类项目，内容见 4.3。
- 老师可以**新增、改名、停用、调整顺序**，给自己的试验加专用项目。
- 每个项目可以自定义要记哪些字段：字段名、单位，以及类型（数字、选项、文字、照片）。
- **录入流程**：选小区（可以多选，比如一次给整块田登记同一次施肥）→ 选项目 → 填日期、数值、照片、备注。日期默认填当天。

### 4.3 录入数据清单

原则：**每一条记录都有日期，能量化的都记数值。** 下表是建议的预设项目，按小麦品种试验的常规记载项目整理，老师可以增删。分级标准（比如倒伏分几级）以老师确认采用的记载标准为准，见第 8 节问题 5。

面积单位默认用亩，可以在设置里改成平方米。

#### A. 基础信息（建档时录一次，之后很少改）

| 对象 | 记录项目 |
|---|---|
| 实验田 | 名称；位置（地址、经纬度）；总面积；**地块形状**（长×宽，或在地图上画出边界）；行数、列数；地势（平地、坡地）；灌溉条件；前茬作物 |
| 小区 | 编号；所在行、列；长、宽、面积；种植行数、行距；是否保护行 |
| 品种 | 品种名称；品种编号或审定编号；选育单位；冬春性（冬性、半冬性、春性）；是否对照品种；备注 |

#### B. 种植记录（每季录一次）

| 记录项目 |
|---|
| 年度；小区；品种；播种日期；播种方式（条播、撒播、穴播）；播种量（kg/亩）；计划基本苗 |

#### C. 生育期（预设，每项记日期）

播种期、出苗期、分蘖期、越冬期、返青期、起身期、拔节期、孕穗期、抽穗期、开花期、灌浆期、成熟期、收获期。

系统根据这些日期**自动计算**全生育期天数和各阶段天数。老师原话里的"拔苗儿"可能是出苗或拔节，两个都已预设。

#### D. 农事操作（每次操作后录）

| 操作 | 记录的数值 |
|---|---|
| 整地 | 方式；深度（cm） |
| 施肥（底肥、追肥） | 肥料名称；类型（氮肥、磷肥、钾肥、复合肥、有机肥）；养分含量（%）；用量（kg/亩）；施用方式 |
| 灌溉 | 方式（漫灌、喷灌、滴灌）；水量（m³/亩） |
| 病虫害防治 | 药剂名称；用量或浓度；防治对象 |
| 除草 | 方式（人工、化学）；药剂；用量 |
| 收获 | 方式（人工、机收） |

#### E. 田间观测（生长期间定期录）

| 类别 | 记录项目 |
|---|---|
| 苗情 | 基本苗（万/亩）；冬前总茎数；最高总茎数；有效穗数（万/亩）；成穗率（%） |
| 植株 | 株高（cm）；穗长（cm）；幼苗习性（匍匐、半匍匐、直立）；叶色；株型（紧凑、中等、松散） |
| 抗逆 | 冻害（越冬冻害、春季冻害）：级别、受害比例（%）<br>**倒伏**：日期、级别、倒伏面积（%）、倒伏角度<br>干旱、渍害、干热风：受害级别 |
| 病害 | 条锈病、叶锈病、白粉病、赤霉病、纹枯病等：严重度（%）、普遍率（%）、抗性等级 |
| 虫害 | 蚜虫等：虫口密度、为害程度 |
| 熟相 | 好、中、差 |
| 照片 | 任意时间拍照，自动关联小区和日期 |

#### F. 收获与考种（收获后录）

| 类别 | 记录项目 |
|---|---|
| 产量 | 小区实收产量（kg）；收获时含水量（%）；系统自动折算亩产（kg/亩） |
| 产量构成 | 穗粒数；千粒重（g）；容重（g/L） |
| 籽粒性状 | 穗型；芒（长芒、短芒、无芒）；壳色；粒色（白、红）；粒质（硬质、软质）；饱满度 |
| 品质（送检后录，可选） | 蛋白质含量（%）；湿面筋含量（%）；稳定时间（min）；沉降值（mL） |

#### G. 土壤（老师第三段话里的参数，阶段一手动录入）

| 记录项目 |
|---|
| 取样日期；取样深度（如 0–20 cm）；取样位置（整块田或某个小区） |
| 土壤类型；质地（砂土、壤土、黏土） |
| **酸碱度 pH** |
| **肥力**：有机质（g/kg）；全氮（g/kg）；碱解氮（mg/kg）；有效磷（mg/kg）；速效钾（mg/kg） |
| 含盐量或电导率；容重（g/cm³）；含水量（%） |

#### H. 气候（阶段一手动录入，阶段二改由气象站自动采集）

| 记录项目 |
|---|
| 日期；平均、最高、最低气温（℃）；降水量（mm）；相对湿度（%）；日照时数（h）；风速（m/s） |
| 系统自动计算：积温；生育期内总降水量 |
| 灾害天气：倒春寒、干热风、大风、冰雹、连阴雨（日期、持续时间、强度） |

### 4.4 可视化与分析

参考九数云仪表板的动态形式。老师给的[链接](https://work.jiushuyun.com/decision/home/space/agqygj6mnz4ublu2tpsnnua7bu)需要登录才能打开，具体要仿照哪些效果需要截图确认（第 8 节问题 1）。目前计划的图表：

| 图表 | 内容 |
|---|---|
| 大田平面图 | 小区网格，按品种、生育期进度或任意指标上色，点击小区查看详情 |
| 多年折线图 | 选品种和指标（如亩产、株高、全生育期天数），横轴是年份 |
| 生长季曲线 | 一个生长季内，某个指标随日期的变化 |
| 品种对比 | 柱状图、雷达图，同时比较产量、抗倒伏、抗病等多项指标 |
| 生育期时间轴 | 各品种从播种到成熟的进度对比 |
| 气候叠加 | 把气温、降水曲线和生育期叠在一起看 |

计划的动态交互：

- 按年度、实验田、品种、指标筛选。
- 图表联动：点一个图里的品种，其他图跟着切换。
- 下钻：实验田 → 小区 → 单条记录。
- 切换时有动画过渡。
- 录入新数据后图表自动刷新。

### 4.5 账号与数据管理

- **角色**：管理员（老师）负责配置实验田、品种和预设项目；录入员（学生）负责录入数据。
- **操作记录**：每条记录保留录入人、录入时间和修改历史。
- **导出**：数据可以导出成 Excel，方便用其他软件做统计（建议项）。

## 5. 阶段二：物联网自动采集

- **传感器**：
  - 土壤温湿度传感器
  - 土壤 pH、电导率、氮磷钾多合一传感器
  - 小型气象站（气温、湿度、降雨、风速风向、光照）
  - 田间摄像头定时拍照（可选）
- **数据合并**：自动采集的数据和手动录入的数据存进同一套结构，标记来源是"传感器"还是"手动"，图表直接共用。
- **设备管理**：设备绑定到实验田或小区，查看在线状态，数据异常时告警。
- 参考代码里的 MQTT + Vert.x 设备接入、设备管理和告警模块，在这个阶段可以复用。

## 6. 阶段三：统计分析与决策

- **品种特性档案**：汇总每个品种多年的产量和产量稳定性，以及抗倒伏、抗寒、抗病等表现，生成品种档案。
- **品种推荐**：输入一块地的土壤和气候条件，推荐合适的试种品种。先用规则匹配，数据积累多了再考虑统计模型。
- **前提**：阶段一、二积累了足够多年的数据。

## 7. 设计要点

- **种植记录是核心**：一条种植记录 = 小区 + 年度 + 品种。生育期、农事操作、观测数据都挂在种植记录下面，这样跨年对比才不会乱。
- **字段不写死**：用"项目定义 + 记录值"的结构实现预设加自定义，以后加新指标不用改数据库表。
- **为阶段二留好位置**：阶段一建表时就给每条观测数据加上"来源"字段，以后传感器数据可以直接接进来。
- **单位统一**：数据库内部统一用一种单位存储，界面上按设置换算显示。

## 8. 仍待确认的问题

1. 九数云的链接需要登录，我看不到。能否截几张图，说明要仿照哪些效果？
2. 除了手机 APP，是否还需要在电脑或大屏上看图表？九数云那种仪表板在大屏上效果更好。
3. 实验田里手机信号怎么样？是否需要离线录入、联网后再自动上传？
4. 试验有没有设对照品种和重复（同一个品种种在几个小区里）？这会影响小区设计和对比分析的算法。
5. 记载项目和分级标准用哪个？例如农业行业标准 NY/T 3923-2021《农作物品种试验规范 粮食作物》，或者学校自己的记载表。4.3 的预设项目要按它来定。
6. 原生 APP 只做 Android，还是 iOS 也要？这会影响技术选型。
