# 小麦品种实验田数字化管理系统 需求分析

v0.6 · 2026-10-30

## 1. 背景与目标

学校的小麦品种实验田按横向、纵向划分成若干小区，每个小区种一个品种，试验连续多年进行。

本系统要把试验过程中的数据数字化：在手机上录入，数据统一存到服务器，用图表呈现。数据积累几年后，再做统计分析和品种推荐。

## 2. 分期

| 期 | 主要内容 |
|---|---|
| 第一期：数据采集与呈现 | 用户和权限管理；手动录入（以手机为主）、导入以前的电子表格、地块平面图、基本统计和图表、大屏展示；预留自动采集接口 |
| 第二期：自动采集 | 传感器自动采集、图像和视频。采集哪些数据、用什么格式，到时再定 |
| 第三期：品种推荐 | 根据积累的数据，结合地块的土壤和气候条件，推荐合适的试种品种 |

## 3. 第一期需求

### 3.1 用户和权限

用户分四级：

| 角色 | 主要工作 | 常用设备 |
|---|---|---|
| 系统管理员 | 系统维护；管理用户账号；增加、删除功能模块。**只做系统管理，不能录入或修改数据** | 电脑 |
| 老师 | 录入、查看、编辑数据；设置实验田、小区和品种；导入历史表格 | 电脑、手机 |
| 学生 | 录入和查看数据 | 手机 |
| 游客 | 只能看大屏展示 | 大屏 |

| 功能 | 系统管理员 | 老师 | 学生 | 游客 |
|---|---|---|---|---|
| 用户管理（增删账号、分配角色、重置密码） | ✓ | | | |
| 功能模块管理（增加、删除、停用） | ✓ | | | |
| 系统维护 | ✓ | | | |
| 设置实验田、小区、品种 | | ✓ | | |
| 录入数据 | | ✓ | ✓ | |
| 修改、删除数据 | | ✓ | | |
| 导入历史电子表格 | | ✓ | | |
| 查看数据和统计 | | ✓ | ✓ | |
| 大屏展示 | | ✓ | ✓ | ✓ |

每条数据都记下录入人和录入时间；修改和删除也留下记录。

### 3.2 实验田和小区

- 设定每块实验田的行数和列数，自动生成小区网格，可以批量给小区编号。
- 每年给小区分配品种和重复号。
- 对照品种：勾选小区建立对照关系，平面图上用虚线连接，并标注"对照品种"。
- 可以把小区标记为保护区或走道。

### 3.3 手动录入

**录入要简单。** 录入主要在手机上完成，界面要尽量少打字，能选的尽量选：

- 在平面图上点选小区，可以一次选多个小区录入同一项，例如同一天施肥；
- 日期默认当天；
- 分级项目（如倒伏程度、病害级别）直接选级别，旁边显示分级标准；
- 品种、操作类型等常用内容从列表里选。

田里没有信号时，数据先存在手机上，有网后再上传。

**录入内容。** 按农业行业标准 NY/T 1301—2025《农作物品种试验与信息化技术规程 小麦》，系统预设以下几类项目，可以增删：

| 类别 | 主要内容 |
|---|---|
| 基础信息 | 实验田（地点、面积、土质、前茬作物）；小区（编号、位置、面积）；品种（名称、编号、是否对照） |
| 农事操作 | 播种、施肥、灌溉、病虫害防治、中耕除草、收获：日期、用量、方法 |
| 物候期 | 播种期、出苗期、抽穗期、扬花期、成熟期；系统自动算出生育期天数 |
| 田间调查 | 株高、基本苗、有效穗数；冻害、倒伏、病虫害等分级项目 |
| 考种和产量 | 每穗粒数、千粒重、容重、小区产量；系统自动折算亩产 |
| 土壤和气候 | 土壤化验结果（肥力、pH 等）；气象数据 |

每个项目的记载方法和分级标准见 [记载标准摘要](记载标准摘要_NY-T1301-2025.md)。

### 3.4 导入历史电子表格

- 以前采集的数据保存在电子表格里，要能导入系统，和新录入的数据一起统计。
- 拿到样表后，再确定表格各列和系统项目的对应关系。

### 3.5 数据呈现和统计

- **地块平面图**：可以拖动、缩放；点击小区查看品种和录入记录；可以按品种或某项指标给小区着色。
- **统计**：按品种汇总（多个重复取平均等）、品种之间对比、多年变化的折线图。图表形式参考九数云，具体效果讨论时确认。
- **大屏展示**：一个专门给大屏用的页面，展示平面图和主要统计图表，数据自动刷新。游客只能看这个页面。
- **导出**：统计结果可以导出成 Excel。

### 3.6 预留自动采集接口

第一期不接传感器，但系统要预留数据接口，第二期接入时不用大改。

## 4. 第二期：自动采集（概要）

- 用传感器自动采集土壤、气象等数据，具体项目和格式待定。
- 图像和视频：田间摄像头、各生育期的照片。
- 自动采集的数据和手动录入的数据一起呈现。

## 5. 第三期：品种推荐（概要）

- 汇总多年数据，总结每个品种的特性，如抗逆性、抗倒伏性。
- 给定一块地的土壤条件（肥力、酸碱度等）和气候条件，推荐合适的试种品种。

## 6. 待讨论的问题

下周和对方沟通时确认：

1. **现有电子表格**：能否提供样表？记录了哪些项目、哪几年的数据？
2. **记录项目**：实际要记哪些项目？标准里的项目哪些不需要，有没有要补充的？
3. **试验设计**：同一个品种是否设重复？对照品种是哪个？小区现在怎么编号？
4. **实验田**：有几块，各分成几行几列？位于哪个麦区？（麦区决定要记哪些病害）
5. **录入人员**：由谁录入，几个人？用自己的手机吗？田里手机信号怎么样？
6. **统计图表**：最常看哪些指标和对比？
7. **"拔苗儿"**：指出苗、间苗，还是拔节？
8. **土壤化验**：在哪里做？测哪些项目？
9. **学生录错了怎么办**：学生能不能修改自己刚录的数据，还是都由老师改？
10. **游客**：看大屏要不要登录？大屏上展示哪些内容？
