# 季、地块和品系

v1.2 · 2026-11-06

这份说明讲需求一（以品系为主线管理种植和数据）做成了什么样、怎么用、编号规则，以及数据怎么存。
第二点"对照比较"以后再做。

v1.1 把原来的"品种比较"并了进来，两套合成一套（见第 5 节）：实验田和每年的试验 → 季和地块，品种 → 品系库。
v1.2：编辑地块有了道路工具（加道路不压缩别的区块）；对照可以是一个小区块，也可以是整个区块当对照组；录入窗口和品系详情的数据重新做了（见第 2 节）。

## 1. 名词

| 名词 | 意思 |
|---|---|
| 季 | 一次种植周期，有名字和起止日期，如"2025-2026 年度大田""2026 夏繁"。一年可以有两季 |
| 地块 | 属于某一季。层级是 地块 → 区块 → 小区块。每季的地块可以重新划 |
| 品系 | 一份有编号的种植材料（口头常说"品种"），分原始材料、杂交组合、选株后代三种 |
| 原始材料 | 没有父母记录的品系，如周麦16、郑麦366 |
| 杂交组合 | 两个品系杂交得到的品系。它本身可以直接种（F1、F2 群体），也可以从它里面选株 |
| 选株后代 | 从某个品系里选出单株，下一季单独种成的品系 |
| 编号 | 品系的"身份证"，建好后永远不变，和种在哪块地块、哪个位置都无关 |
| 名称 | 给人看的叫法，可以改，旧名留作曾用名 |
| 系谱式 | 系统按系谱自动写出的亲本组合，如"周麦16/郑麦366" |
| 世代 | 杂交后代这一季种的是 F 几 |
| 系谱图 | 品系之间父母、子代关系的图（不是基因连锁图） |

## 2. 怎么用

左侧菜单：日常（首页、季和地块、数据查看、数据质量、更正申请）、品种（品系库、系谱图）、统计（统计分析、自助分析、数据大屏）、资料（录入项目、导入历史表格）。只有老师能新建季、地块、品系，做杂交、选株、种植、改种、淘汰；学生录入和查看。

1. **季和地块**：新建季时选"接着哪一季"（可以选几季，比如同时接着去年大田和夏繁），第一季选"全新开始"。在季里新建地块：照着以前某块地块的区块划分建（只要划分，不带种植和数据），或者从空白开始——只定区块几行几列、每个区块多大、横向和纵向路宽，不用先定地块总长宽。建好后自动打开平面图的"布置试验"。以前各季地块的划分和数据保持原样。
   - **编辑地块**里的道路工具（`R`）：点两个区块之间的线加一条道路，点道路删掉；别的区块不变小，地块跟着变大。拖区块之间的线也是地块跟着变（按住 `Shift` 才是两边一起变）。一整行区块改成道路自动收窄，整条道路改回区块按旁边区块放宽。详见《地块布局与记载本》1.2。
2. **原始材料**：季和地块、品系库、系谱图、平面图右侧都能新建，一行一个名字，可以一次建多个；也可以把原来品种比较里的品种拿来用。
3. **种植**（平面图"布置试验"）：
   - 右侧"种什么"列出接着的季种过的品系、它们的子代、这一季已经种了的、最近种过的，可以搜全部品系；
   - 拖到小区块上种这一格，拖到区块名称牌上整块种，先选好几个小区块再拖到其中一个上一次种好几个；选中小区块后点品系也能种；
   - 右键小区块"种植"、右键区块（名称牌）"整块种"，子菜单里直接选；
   - 整块种以后还可以把其中几个小区块单独改种；已经录了数据的小区块不能改种。
4. **选株**：在平面图上选中种着同一个品系的小区块（同一个区块里），点"选株"或右键"选株"，自动记下从哪里选的；也可以在品系详情、系谱图里选株（要说是哪一季）。一次可以选多株，填挂牌号，当场录每一株的数据（选出时的单株数据）。
5. **杂交**：平面图上选中种着两个品系的小区块，点"杂交"（先选的是母本）；系谱图里点一个品系、按住 Ctrl 再点一个；也可以在品系库、品系详情里杂交。同样的父母以前做过时会提示。
6. **录入**：在平面图上选中位置（`Enter`）打开录入窗口，数据归到那里种的品系名下。
   - 左边选项目：能搜，最近录过的在最上面，按分类分组，★ 是重要项目，只选一个小区块时已经录过的打 ✓；
   - 右边一张卡片：项目名和单位、什么时候调查和怎么记（记载标准）、填值（分级的做成大牌子，下面写标准）、调查日期（今天、昨天、前天一点就好）、备注；上面写着以前录的（一个小区块是上次的值和日期，几个是已经录过几个、平均多少）；
   - `Ctrl+Enter` 保存并录下一项。选中的正好是一个整块种的区块时，小区产量、杂株数可以按整块录一个总数，系统按面积分到各小区块（合计等于这个数，折合亩产不变）。学生录错了照旧提交更正申请。
7. **对照**（布置试验 →"设对照"，选一个小区块也行）：
   - 小区块当对照：选中的小区块里点出哪几个是对照（种了对照品种的默认点上），别的和它比；
   - 整个区块当对照组：点区块名称牌选中整个区块再点"设对照"，这个区块里的小区块都是对照，别的和这一组的平均比；
   - 和谁比：选中的其余小区块，或者地块里其他所有小区块。
   - 平面图上不画连线：对照小区块描红边、标 CK，对照区块整块描红边、挂"对照组"；在右边点一组（或点一个比较的小区块），比较的小区块描虚线框，右边"和对照比"选项目，看对照（组）的平均值和每个小区块比对照高多少，按高低排，格子够大时格子右上角也写着。
8. **查看**：
   - 系谱图：按季分列，母本实线、父本虚线、选株点线；点一个品系高亮它的祖先和后代，右边显示系谱式、每季种在哪、重要数据；可以搜、按组合折叠、只看某几季、显示淘汰的；
   - 平面图上选中一个小区块：右侧显示种的品系、世代、来源，一键打开父母当季的地块并高亮父母种的位置；精简版系谱图高亮它的家系；
   - 品系详情：父母和子代、父母当季种在哪、每季种在哪、选出时的单株数据、导出 Excel；"各季的数据"每个项目一张卡片：
     - 数值：大字是这一季各位置的平均，旁边写几个位置、最小到最大、比上一季高低多少；一条横轴上画出每个位置的点、平均线、对比品系的平均（三角）和选出时的单株（菱形）；
     - 选项（株型、穗型……）：每种有几个位置，一条一条的横条，如"直立 24 个"；日期：平均日期、最早到最晚；
     - 下面一排是各季的值，点一季换着看（默认看最近录得差不多的一季）；"按区块看各位置"展开，按地块、区块列出每个小区块的值；
     - 默认和父母比，还可以加对照品种、兄弟品系、子代，写着本品系比它高多少；它没和本品系同一季种时用它最近一季的数据，并注明是哪一季。
9. **淘汰整理**：新的一季布置好以后，在季和地块里点"淘汰整理"，系统列出接着的季里种过、这一季没再种、也没有子代的在选品系，老师一个个定淘汰、保留还是先不管。淘汰的在系谱图里默认不显示，可以恢复；有子代或种过的品系不能删，只能淘汰。

手机端这次只做了最少的改动：换地时能看到育种的地块（带季名），选小区块离线录入，显示品系名；系谱图和品系库先只在电脑端。

## 3. 编号和命名规则

1. **原始材料**：名称用原名（如周麦16）；编号可以填（如引种时的材料编号），不填就用名称当编号。
2. **杂交组合**：编号 = 杂交年份后两位 + "-" + 当年第几个杂交组合，如 25-001、25-002。
   - 序号由系统按建的先后自动数，三位，每年从 001 重新数，超过 999 自动变四位；
   - 杂交年份不填时按这一季算：有结束日期按结束那年（2024-2025 年度大田算 2025），否则按开始那年；
   - 母本、父本对调（正反交）算不同的组合；同样的父母以后再杂交一次，也是新组合、新编号。
3. **选株后代**：编号 = 父编号 + "-" + 从它里面选出的第几株，如 25-001-3，再选是 25-001-3-2；从原始材料选出的如 周麦16-1。第几株按选出的先后自动数，以后再从同一个品系选接着往下数；田间挂牌号另记一栏，不放进编号。
4. **系谱式**（Purdy 写法），系统按系谱图自动写，母本在前，用品系当前的名称：
   - 单交：周麦16/郑麦366；
   - 第二次杂交用"//"：周麦16/郑麦366//百农207；第三次用"/3/"，再往上用"/4/"……；
   - 回交在重复用的亲本后面写"*次数"：周麦16*2/郑麦366；
   - 选株后代的系谱式和父本相同，选了几次看编号。
5. **名称**：默认等于编号；可以改成代号或审定名（如"校麦1号"），旧名都留作曾用名，按名称、曾用名、编号都能搜到。名称全系统唯一（和品种一起算），不能含"/"和"*"。改名后系谱式自动用新名字，编号不变，以后选出的后代编号也照旧。
6. **世代**：只给杂交后代标。杂交组合第一次种是 F1；同一个品系再种一季加一代；选株后代第一次种 = 选出时的世代 + 1（从 F2 里选的单株，下一季种是 F3）。世代记在每季的种植记录上，自动算，可以在平面图上改（比如用的是存的老种子）。
7. 编号和序号由服务器统一分配，两个人同时建也不会重号。

## 4. 数据怎么存

| 表 | 内容 |
|---|---|
| `season`、`season_follow` | 季，以及这一季接着哪几季 |
| `field.season_id` | 地块就是属于某一季的实验田，区块布局沿用 `field.layout` |
| `control_link`、`control_link_plot` | 对照：一组里哪些小区块是对照（`is_control`），哪些和它比；整个区块当对照组时就是这个区块的小区块都是对照 |
| `trial` | 每块地块自带一个试验（新建时类型是育种圃 `BREEDING`，可以改），跟着地块建、删 |
| `variety` 的品系列 | 品系存在品种表里：`line_kind`（原始材料、杂交组合、选株后代）、`line_code`（编号）、`mother_id`、`father_id`、`parent_id`、`line_status`、`former_names`、`origin_season_id`、`origin_field_id`、`origin_block_id`、`origin_plot_id`、`seq_no`、`cross_year`、`tag_no` |
| `planting.generation` | 世代 |
| `line_plant_value` | 选出时的单株数据 |

- 数据仍然记在"种植记录"（地块的试验 + 小区块）上，同时归到那里种的品系名下：同一个品系换了年份、地块，表现差别很大，统计和数据质量检查要用到位置和重复。
- 品系存在品种表里，所以平面图、录入、手机端、统计显示名字都不用改。
- 土壤、气象、传感器数据按位置和日期记，不归品系。
- 后端代码在 `server/.../breeding/`：`SeasonService`（季和地块）、`LineService`（品系、编号、种植、世代、候选品系、淘汰整理）、`LineDetailService`（品系详情、各季数据、单株数据）、`Pedigree`（编号格式、系谱式）、`BreedingIndex`（一次取出全部季、地块、种植记录和品系）。
- 接口：`/api/seasons`、`/api/lines`、`/api/breeding/fields/{id}`；功能模块 `breeding` 可以停用。

演示数据：后端用 local 配置启动后运行 `node scripts/seed-breeding.mjs`，按验收场景建四季的数据（老师 `laoshi`，密码 `demo1234`）。

## 5. 原来的实验田、试验、品种怎么并进来

- **实验田和试验 → 季和地块**（迁移 V13）：原来的实验田每一年的试验变成那一季（"2024-2025 年度大田"，有同名的季就用它）的一块地块。
  第一年用原来的实验田，以后各年复制一块（区块划分、小区块编号一样），那一年的种植记录、对照关系搬过去；录入的数据、记载本、更正申请都还挂在原来的试验上。转来的季按年份连起来。
- **每块地块这一季就是一个试验**：平面图"试验"里改试验类型（区域试验、品比试验、观察圃、育种圃……）、麦区、重复次数；
  记载本、设重复、设对照、统计分析、数据质量、导入历史表格、数据大屏都照常用。地块的试验跟着地块，不能单独删。
- **品种 → 品系库**：品种就是原始材料，统一编号、选育单位、对照类型在品系库里改；新加的品种（导入历史表格时自动新增的也是）都是原始材料。
- **同一块地的各季**：同名的地块连起来（各季的"东区品种试验田"），统计分析的历年变化、数据大屏的趋势、自助分析按地块筛选都按它算。
- 首页、顶栏切换只看现在这一季的地块；各页面选地块时带上季名。
