# 地块布局与试验记载本

v0.4 · 2026-11-11

这份说明讲两件事：实验田怎么按"区块"布置（平面图），以及《河南省小麦品种试验记载本（2024-2025）》的字段怎么合并进系统。

v0.4：地块布局从"几行几列区块的表格"改成了"随便摆的矩形"——区块、道路都可以直接画、拖、拉、删，道路不用再整行整列地加（见 1.2）。

## 1. 地块布局：地块 → 区块 → 小区块

地块是一个矩形。**区块**、**道路**是摆在地块里的矩形，位置和大小随便改；每个种植区块里再分几行几列**小区块**。小区块是录入数据的单位。

| 概念 | 说明 |
|---|---|
| 地块 | 一个矩形，有宽和长。没被区块、道路盖住的地方就是空着的地 |
| 区块 | 一个矩形：离地块左边、上边多远，多宽多长。类型有种植区块（里面分小区块）、道路、保护区、空地 |
| 道路 | 也是一个矩形（长条），想画在哪儿就画在哪儿，可以只画一段，不用通到头；道路和道路可以交叉 |
| 不能叠 | 区块和区块、道路和区块不能叠在一起（叠着的描红，不能保存） |
| 长度单位 | 米、厘米、尺、步、丈、英尺，也可以自己定（名称 + 1 单位等于多少米）。换单位时可以换算数字（实际大小不变），也可以只改单位名 |
| 格子类型 | 区块里的每一格（小区块）也可以是种植小区块、道路、保护区、空地；保存布局后小区块类型跟着变 |
| 合并 | 几个区块可以合并成一个；区块里的几个小区块也可以合并成一个 |
| 真北方向 | 图纸上方顺时针转多少度是北 |

### 1.1 新建地块

在"季和地块"里新建地块（从空白开始）时只定：区块几行几列、每个区块多宽多长、每个区块里小区块几行几列、横向道路（上下两排区块之间）和纵向道路（左右两列之间）多宽（0 表示不留）。**不用先定地块的总长宽**：地块大小就是区块和道路加起来，右边预览下面写着现在多大。这只是起个头，建好以后每个区块、每条道路都可以单独再改。

### 1.2 编辑地块（平面图 →"编辑地块"，老师）

改动先记在草稿里，`Ctrl+Z` 撤销、`Ctrl+Y` 重做，点"保存布局"才提交。底部显示这次会去掉几个小区块、新建几个、有几处叠在一起。

**区块、道路都是直接摆的：**

| 想做的事 | 怎么做 |
|---|---|
| 挪位置 | 按住区块（或道路）直接拖。靠近别的区块的边、地块的边会自动贴住；离别的区块正好一个路宽时也会贴住（正好留出一条路）。按住 `Ctrl` 不贴，按住 `Shift` 只横着或竖着挪，方向键一点点挪（`Shift` 挪得多） |
| 改大小 | 选中后拖四周的小方块；或者在右边填宽、长。种植区块改大小时里面的小区块按比例跟着变 |
| 按小区块大小定区块 | 右边"每个小区块多大"填宽、长：区块大小按"行列数 × 小区块大小"重新算 |
| 画道路 | 右下角道路工具（`R`）：按住拖，从哪儿拖到哪儿路就画到哪儿（横着拖是横向道路，竖着拖是纵向）。上面的小条里改路宽 |
| 加一条通到头的道路 | 道路工具下把鼠标移到区块的边、或小区块之间的线上，预览出一条通到地块两头的道路，点一下加上 |
| 画区块 | 区块工具（`B`）：按住拖出一个方框。里面按现有小区块的大小分行列；画到地块外面，地块跟着变大 |
| 复制 | `Ctrl+D`（或 `Ctrl+C`、`Ctrl+V`）；拖动时按住 `Alt` 松手是复制一份过去。复制出来的区块一样大、一样的行列，小区块是新的 |
| 照着排一片 | 选一个区块 →"照着排一片"：横着几个、竖着几个、间隔多少，一次排出一样的几行几列区块 |
| 删除 | `Delete`。删道路时空出来的地方留着；右键"删掉这条道路并合拢"会把后面的收回来 |
| 选几个 | Ctrl/Shift 单击加选；拖动框选；`Ctrl+A` 全选。选了几个可以一起拖 |
| 对齐、排开 | 选几个 → 右边"对齐和排开"：靠左、居中、靠上……；"一个挨一个排"（中间隔填的间隔）、"匀开" |
| 合并区块 | 选两个或更多 →"合并成一个"（夹在中间的道路一起选上就并进来）。弹出合并窗口：名称、类型，小区块"保留原来的拼起来"（排得整齐、行列对得上时）或"重新分几行几列"。重新分时原来的小区块按实际位置放进新格子，编号、品种、数据都跟着 |
| 拆开区块 | 选一个 →"拆成几块"：拆成几行几列个区块，按小区块之间的线拆，小区块都留着。拆完还在原地，可以再拖开、在中间画路 |
| 改地块大小 | 拖地块的右边、下边，或者什么都不选时在右边填宽、长；"收紧到正好放下"去掉四周空着的边 |
| 改区块类型 | 右边"类型"：种植区块、道路、保护区、空地 |
| 改区块里的小区块 | 双击种植区块进去：改小区块行列数、拖小区块之间的线改行高列宽、框选几个小区块合并、拆开 |
| 格子类型 | 区块里选中格子（点选、框选、点行号列号），右边或右键设成种植小区块、道路、保护区、空地。已经分配了品种的小区块不能改成道路等，要先清掉品种 |
| 挪小区块 | 区块里选中格子，拖到别的位置：小区块（编号、品种、数据）跟着挪，挪到的地方原来的小区块换过来 |
| 真北方向 | 整块地（什么都不选）时右边"真北方向"：北在上/右/下/左，或填角度 |

**画道路时别的区块不会被压小：**

- 路画在空地上（区块之间的空当里）：就放在那儿，别的都不动。
- 路压到了区块：在离路最近的分界线处放路。分界线在区块里面（小区块之间）时，区块在这里**切开**成两个区块，前面的不动，后面的往后挪一个路宽；分界线是区块的边时，旁边有空当先占空当，空当不够宽才把后面的往后顶，差多少顶多少。
- 往后挪的东西顶到别的，别的跟着让；跨过去的垂直道路跟着变长，原来通到地块边上的道路还通到边上。小区块的大小、编号、品种、数据都不变，地块跟着变大。
- 路的两头落在区块里面时：盖住一半以上就延长到区块那头，否则缩回到区块边上。
- 被合并的小区块跨着的线不能切。
- 改道路的宽（右边"路宽"）也一样：变宽了后面的往后挪，变窄了收回来。

拖动、画的时候旁边有提示：现在的位置和大小、会切开几个区块、后面的挪多少、地块变成多大。

保存时服务器按布局增删小区块：已经分配了品种、设了重复、录了数据或设了对照的小区块不能去掉，会提示先在"布置试验"里清掉。小区块的长和宽按布局算（单位换成米），折合亩产用得上。

### 1.3 看平面图

平面图整页都是地图：页头一行放实验田、试验、今天的情况（生育期、今天已录、异常、本周录入）；地图上左上角切换模式（录入数据、布置试验、编辑地块，`1`/`2`/`3`）和找小区，右上角切换视角和着色，右下角是工具和缩放，选中后底部浮出操作条；右边面板按选中的东西显示（`]` 收起）。按 `?` 看全部快捷键。

- **俯视图（固定视角）**：平面图，可以选、可以编辑。图纸朝上或正北朝上（`N` 或点指北针切换）；滚轮缩放（朝鼠标处），按住空格或滚轮拖动，`F` 适应窗口；`M` 测距，点两下量距离；左下角是比例尺和鼠标离地块中心往东、往北多少米。
- **3D（自由视角）**：`T` 切换。小区立起来，高度按长势（没种、生长中、有异常、已收获）；"按指标"着色时高度按指标的值，像铺在地上的立体柱状图。左键拖动转，右键拖动平移，滚轮缩放；单击选小区，`Ctrl` 单击加选，`Shift` 拖动框选，双击看详情。可以一键俯看、斜看、从东南西北看，"转"慢慢绕着转（投屏展示）。编辑地块只在俯视图里。
- 双击区块的名称牌进入区块，只看这个区块；点上面、左边的行号列号选整行整列；`Esc` 返回整块地。点名称牌选中这个区块的所有小区。
- **找小区**：左上角输编号或品种名（`/` 或 `Ctrl+F`），回车放大过去并选中；`Shift+回车` 选中全部匹配的（例如某个品种的所有小区）。
- **选中一个小区**：右边面板显示品种、重复、状态和最近录的数据；方向键选旁边的小区，回车录入。
- **选中几个小区**：右边面板列出品种、重复、状态各几个，点一项选中地里所有同样的小区；图例里点一项也一样；右键菜单有"选中同品种的小区""选中同一重复的小区"。
- "布置试验"里有"一个区块一个重复"：区块1 → 重复Ⅰ，区块2 → 重复Ⅱ……

平面图直接用 Konva 画（不经过 Vue 模板），缩放、平移只改变换，点到哪个格子按坐标自己算：720 个小区的地块点选、框选都在一帧内，整张重画约 4 ms。3D 用 three.js，点开时才加载。

### 1.4 和其它功能的关系

- **手机端**：区块布局的地按区块显示——上面一排区块标签（只看某一个区块时格子放大），每个区块一张卡片，合并的小区占几格画几格，"选整块"选整个区块，点区块里的行号列号选一行一列。小区页写"区块2 · 第 1 行第 2 列"。
- **首页、数据大屏**：实验田缩略图按区块布局的实际比例画（`BlockMiniMap.vue`），大屏是深色版。
- **小区详情、平面图鼠标提示**：写小区在哪个区块的第几行第几列。
- **导入历史表格、数据查看**：还按小区编号和"拉平"后的行列找小区：服务器把区块布局拉平成一个网格——先按种植区块左上角的位置排出"第几排、第几列区块"（上边一样高的算一排，左边对齐的算一列），每一排区块占的行数是这一排里各区块小区块行数的最大值，列同理。区块不叠在一起，行号列号就不会重复。

以前按行列建的实验田读出来是整块地一个区块，原样保存一次就变成区块布局。

数据存在 `field.layout`（JSON，`version` 为 2）：地块的宽 `w`、长 `h`，`blocks` 里每个区块、道路的 `x`、`y`、`w`、`h`、类型和小区块网格 `inner`。字段定义见 `server/.../field/FieldLayout.java` 和 `client/src/shared/fieldLayout.ts`，摆放、画路、合并、拆开的计算都在后一个文件里（纯函数，有单元测试），拖动时的贴边在 `client/src/shared/layoutSnap.ts`。

以前（v0.3 及更早）布局是"几行几列区块 + 合并"的表格（`version` 为 1：`rows`、`cols`、`merges`，区块记行号列号，特殊区块记 `fit`）。数据库迁移 `V15__Free_layout` 把存着的布局都换成了现在的样子：位置和大小和原来画出来的一样，整行整列的道路变成一条通到头的道路，特殊区块四周空出来的地方补上道路，小区块、种植、数据都不动。

## 2. 河南省小麦品种试验记载本

记载本（河南省农业科学院小麦研究中心制，2015.9 修订，2024-2025 年度）有 11 张表。按记的是"每个小区"还是"整个试验"分两类合并：

| 记载本的表 | 系统里 |
|---|---|
| 四、田间记载（Ⅰ、Ⅱ、Ⅲ重复） | 录入项目，按小区录入或导入 |
| 五、性状汇总表 | 统计分析的"品种主要性状汇总表" |
| 六、室内考种结果 | 录入项目（每穗粒数、千粒重、容重、黑胚率等） |
| 九、产量表 | 录入项目"小区产量"，折合亩产按收获面积算 |
| 封面、一、试验设计、二、栽培管理、产量计算参数 | 试验记载本 → 基本情况 |
| 三、气象资料 | 试验记载本 → 气象资料（9 月到 6 月，当年和常年） |
| 十、品种评价 | 试验记载本 → 品种评价（气象分析 + 分品种评价） |
| 田间种植图 | 平面图（区块布局） |

### 2.1 试验记载本

平面图上方"记载本"打开（老师填写，学生能看）。第一次打开时，年度、试验区别、地点、经纬度、海拔、前茬、土质、水旱地、试验田面积、供试品种数、共同对照、重复次数、小区尺寸按已有资料先填好。

右上角"导出记载本"（平面图"更多"里也有）按记载本的样子导出一个 Excel：封面、田间种植图（按重复列小区号和品种）、基本情况、气象资料、田间记载（按重复分段，表头和单位行同记载本，日期 YY-MM-DD，幼苗习性、熟相、落粒性写 1/3/5 级）、室内考种（按品种，各重复和平均）、产量表（小区产量、折亩产，各重复和平均，±% 比试验平均，位次，计产参数）、品种评价。每个小区取每个项目最近一次录的值。

产量计算参数按记载本的公式：**收获面积 = 收获长 ×［(小区行数 − 1) × 行距 + 畦埂宽］**（长用米，行距和畦埂宽用厘米），收获长没填时用小区长度；也可以直接填收获面积。保存后，这个试验的折合亩产、标准面积小区产量都按收获面积算；清空参数后回到按小区的长 × 宽算。

### 2.3 和 NY/T 1301—2025 写法不同的地方

已写进对应录入项目的说明里：

- 冬冻、春冻程度：记载本按地上部冻害分五级（1 无冻害；2 叶尖受冻发黄；3 叶片冻死一半；4 叶片全枯；5 植株或大部分分蘖冻死），标准按死茎率分级。
- 倒伏：记载本记"第 1 次""第 2 次"，对应标准的"最初""最终"；倒伏面积填整数（35% 填 35）。
- 基本苗、最高分蘖、亩成穗保留 1 位小数；株高四舍五入为整数；小区产量保留 2 位小数。
- 穗发芽：记载本按无、轻、重三级目测，标准记穗发芽率（%），两项都保留。

数据在 `server/src/main/resources/db/seed/record-book-henan-2024.json`，由迁移 `V6__Seed_record_book_fields` 写入；已经有的别名和说明不覆盖。
