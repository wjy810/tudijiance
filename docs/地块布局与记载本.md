# 地块布局与试验记载本

v0.1 · 2026-11-04

这份说明讲两件事：实验田怎么按"区块"布置（平面图），以及《河南省小麦品种试验记载本（2024-2025）》的字段怎么合并进系统。

## 1. 地块布局：实验田 → 区块 → 小区

一块实验田先分成几行几列**区块**，每个区块里再分几行几列**小区**。小区是录入数据的单位。

| 概念 | 说明 |
|---|---|
| 区块网格 | 每一行区块有自己的高、每一列区块有自己的宽 |
| 长度单位 | 米、厘米、尺、步、丈、英尺，也可以自己定（名称 + 1 单位等于多少米）。换单位时可以换算数字（实际大小不变），也可以只改单位名 |
| 区块类型 | 种植区块（里面分小区）、道路、保护区、空地 |
| 合并 | 几个区块可以合并成一个；区块里的几个小区也可以合并成一个 |
| 特殊区块 | 把区块设得比原来的位置（槽位）小，槽位里其余的地方是道路；区块可以在槽位里拖动、对齐 |
| 真北方向 | 图纸上方顺时针转多少度是北 |

### 1.1 新建实验田

首页"新建实验田"里设：长度单位、区块几行几列、每个区块的宽和高、区块之间的道路宽（0 表示不留）、每个区块里小区几行几列。右边有预览，下面算出共几个区块、几个小区、整块地多大、每个小区多大。有三个常用做法可以一键填好：区试 3 个重复、品比 4 个重复、整块地一个区块。

### 1.2 编辑地块（平面图 →"编辑地块"，老师）

改动先记在草稿里，`Ctrl+Z` 撤销、`Ctrl+Y` 重做，点"保存布局"才提交。底部显示这次会去掉几个小区、新建几个小区。

| 想做的事 | 怎么做 |
|---|---|
| 选区块 | 单击；Ctrl/Shift 单击加选；拖动框选 |
| 合并区块 | 选几个区块 →"合并"。各区块小区的行列对得上时，拼成一个大区块，小区都保留；对不上时只留左上角区块的小区 |
| 拆开区块 | 选合并过的区块 →"拆开"。能按原来的边界切开时，小区分回各个区块 |
| 改一整列宽、一整行高 | 点上面、左边标尺上的尺寸，在右边改；还可以插入、删除一行（列）区块 |
| 改区块类型 | 右边"类型"：种植区块、道路、保护区、空地 |
| 改区块里的小区 | 双击区块进去：改小区行列数、单独改某一行高（某一列宽，其余按比例分）、框选几个小区合并、拆开 |
| 特殊区块 | 选一个区块 →"设成特殊区块"，填宽高或直接在图上拖动；可以靠左、居中、靠右、靠上、靠下，一键恢复填满 |
| 真北方向 | 整块地（什么都不选）时右边"真北方向"：北在上/右/下/左、填角度，或"以现在屏幕上方为北" |

保存时服务器按布局增删小区：已经分配了品种、设了重复、录了数据或设了对照的小区不能去掉，会提示先在"布置试验"里清掉。小区的长和宽按布局算（单位换成米），折合亩产用得上。

### 1.3 看平面图

- 双击区块的名称牌进入区块，只看这个区块；点上面、左边的行号列号选整行整列；`Esc` 返回整块地。点名称牌选中这个区块的所有小区。
- **自由视角**：滚轮缩放，按住空格或滚轮拖动；`Shift` + 滚轮、`Q`/`E`、右下角按钮或拖动指北针旋转。
- **固定视角**：图纸朝上或正北朝上，不能拖动、缩放、旋转，总是正好放下整块地，适合投屏和打印。
- 指北针指着北，点一下（或按 `N`）北朝上；画面四边标出朝哪个方向；右下角显示鼠标位置离地块中心往东、往北多少米。
- "布置试验"里有"一个区块一个重复"：区块1 → 重复Ⅰ，区块2 → 重复Ⅱ……

### 1.4 和其它功能的关系

- **手机端**：区块布局的地按区块显示——上面一排区块标签（只看某一个区块时格子放大），每个区块一张卡片，合并的小区占几格画几格，"选整块"选整个区块，点区块里的行号列号选一行一列。小区页写"区块2 · 第 1 行第 2 列"。
- **首页、数据大屏**：实验田缩略图按区块布局的实际比例画（`BlockMiniMap.vue`），大屏是深色版。
- **小区详情、平面图鼠标提示**：写小区在哪个区块的第几行第几列。
- **导入历史表格、数据查看**：还按小区编号和"拉平"后的行列找小区：服务器把区块布局拉平成一个网格——每一行区块占的行数是这一行里各区块小区行数的最大值（道路、空地不占），列同理。

以前按行列建的实验田读出来是整块地一个区块，原样保存一次就变成区块布局。

数据存在 `field.layout`（JSON），字段定义见 `server/.../field/FieldLayout.java` 和 `client/src/shared/fieldLayout.ts`。

## 2. 河南省小麦品种试验记载本

记载本（河南省农业科学院小麦研究中心制，2015.9 修订，2024-2025 年度）有 11 张表。按记的是"每个小区"还是"整个试验"分两类合并：

| 记载本的表 | 系统里 |
|---|---|
| 四、田间记载（Ⅰ、Ⅱ、Ⅲ重复） | 录入项目，按小区录入或导入 |
| 五、性状汇总表 | 统计分析的"品种主要性状汇总表" |
| 六、室内考种结果 | 录入项目（每穗粒数、千粒重、容重、黑胚率等） |
| 九、产量表 | 录入项目"小区产量"，折合亩产按收获面积算 |
| 封面、一、试验设计、二、栽培管理、产量计算参数 | 试验记载本 → 基本情况 |
| 三、气象资料 | 试验记载本 → 气象资料（9 月到 6 月，当年和常年） |
| 十、品种评价 | 试验记载本 → 品种评价（气象分析 + 分品种评价） |
| 田间种植图 | 平面图（区块布局） |

### 2.1 试验记载本

平面图上方"记载本"打开（老师填写，学生能看）。第一次打开时，年度、试验区别、地点、经纬度、海拔、前茬、土质、水旱地、试验田面积、供试品种数、共同对照、重复次数、小区尺寸按已有资料先填好。

右上角"导出记载本"（平面图"更多"里也有）按记载本的样子导出一个 Excel：封面、田间种植图（按重复列小区号和品种）、基本情况、气象资料、田间记载（按重复分段，表头和单位行同记载本，日期 YY-MM-DD，幼苗习性、熟相、落粒性写 1/3/5 级）、室内考种（按品种，各重复和平均）、产量表（小区产量、折亩产，各重复和平均，±% 比试验平均，位次，计产参数）、品种评价。每个小区取每个项目最近一次录的值。

产量计算参数按记载本的公式：**收获面积 = 收获长 ×［(小区行数 − 1) × 行距 + 畦埂宽］**（长用米，行距和畦埂宽用厘米），收获长没填时用小区长度；也可以直接填收获面积。保存后，这个试验的折合亩产、标准面积小区产量都按收获面积算；清空参数后回到按小区的长 × 宽算。

### 2.3 和 NY/T 1301—2025 写法不同的地方

已写进对应录入项目的说明里：

- 冬冻、春冻程度：记载本按地上部冻害分五级（1 无冻害；2 叶尖受冻发黄；3 叶片冻死一半；4 叶片全枯；5 植株或大部分分蘖冻死），标准按死茎率分级。
- 倒伏：记载本记"第 1 次""第 2 次"，对应标准的"最初""最终"；倒伏面积填整数（35% 填 35）。
- 基本苗、最高分蘖、亩成穗保留 1 位小数；株高四舍五入为整数；小区产量保留 2 位小数。
- 穗发芽：记载本按无、轻、重三级目测，标准记穗发芽率（%），两项都保留。

数据在 `server/src/main/resources/db/seed/record-book-henan-2024.json`，由迁移 `V6__Seed_record_book_fields` 写入；已经有的别名和说明不覆盖。
